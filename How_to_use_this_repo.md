# How to use this repo

1. Fork this repo to your own Github account
2. Clone you forked repo to the plaform you want to use. **NOTE:** Skip the Setup the plaform steps if you are ***NOT*** prepaing a dedicated machine.
3. Read and use the instructions in the **Setup the plaform/SetupHardware.md**
4. Then see the README.md file in **Data_Engineering_Profiles/1_Python_Data_Engineer**
